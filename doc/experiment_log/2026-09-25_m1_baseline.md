# 2026-09-25 — M1: baseline ΛCDM

**Goal:** Milestone M1. Freeze the reference cosmology `baseline_lcdm` and save its observables.

## Configuration

- `configs/baseline.yaml`: Planck-2018-like values.
  - ω_b = 0.02237, ω_dm = 0.1200, 100θ_s = 1.04190, n_s = 0.9649, ln(10¹⁰A_s) = 3.044, τ = 0.0544.
  - N_ur = 2.0328 with one massive neutrino of 0.06 eV. YHe from BBN.
  - Outputs: lensed TT/TE/EE/BB up to ℓ = 2500, φφ, and P(k, z=0) on 400 log-spaced points from 10⁻⁴ to 10 h/Mpc.
- CLASS v3.4.0 @ `64bbab7`. The precision block is described below.

## What was run

```bash
uv run python src/run_baseline.py
```

Outputs: `results/spectra/baseline_lcdm.npz` (arrays) and `results/spectra/baseline_lcdm.json` (the exact CLASS parameter dictionary, derived parameters, runtime and classy version).

## Outcome

- Derived: h = 0.67377, σ₈ = 0.81071, Ω_m = 0.31504, z_rec = 1088.78, r_s(rec) = 144.53 Mpc. Runtime ~1.2 s.
- **First attempt used 100θ_s = 1.04110 and was discarded.** That is Planck's θ_MC, a different approximation from CLASS's θ_s, and it gave h = 0.671. CLASS θ_s for Planck-2018 cosmology is ≈ 1.0419.
- The baseline was **re-frozen once**, with the precision settings adopted in M2a (4× thermodynamics table, 10× earlier perturbation start). Default-precision CLASS changes C_ℓ by up to ~2×10⁻³ under trivial changes to the thermodynamics sampling (see the M2a entry), so the baseline has to be computed with the same converged settings as every other model.
